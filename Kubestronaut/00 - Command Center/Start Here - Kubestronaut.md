## Start here

Use this note when opening the Kubestronaut vault.

## If studying today

1. Open [[Kubestronaut HQ]].
2. Check Today's tasks.
3. Open today's daily learning note.
4. Study, lab, recall, and record weak areas.
5. Update actual_minutes and confidence.

## If reviewing progress

- Open [[Learning Analytics]].
- Open [[Certification Dashboard]].
- Open the active tracker, currently [[KCNA Tracker]].

## If practicing Kubernetes

- Open [[Lab Dashboard]].
- Use [[kubectl Command Reference]].
- Link results to concept notes in [[Knowledge Base Dashboard]].

## If debugging

- Open [[Troubleshooting Dashboard]].
- Start from symptoms, events, describe output, and logs.
- Link the incident to relevant concept notes.

## If preparing for an exam

- Open [[Mock Exam Dashboard]].
- Follow [[Exam Readiness Protocol]].
- Use [[Exam Booking Decision Checklist]] before booking.

## If cleaning up the vault

- Open [[Maintenance Dashboard]].
- Run [[Weekly Maintenance Routine]].
- Check [[Final Integration Checklist]] monthly.
