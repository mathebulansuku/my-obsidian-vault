## Evidence rules

- [ ] Official pass status is blank unless verified result exists #kubestronaut #maintenance #certification
- [ ] Readiness scores are based on evidence, not optimism #kubestronaut #maintenance #certification
- [ ] Mock exams do not create official pass status #kubestronaut #maintenance #mock-exam
- [ ] Weak areas are updated after labs, troubleshooting, and mocks #kubestronaut #maintenance #review

## Safety rules

- [ ] No kubeconfigs are stored in the vault #kubestronaut #maintenance #security
- [ ] No AWS credentials are stored in the vault #kubestronaut #maintenance #security
- [ ] No tokens, passwords, private keys, or real secret values are stored in the vault #kubestronaut #maintenance #security
- [ ] Secret examples use placeholders only #kubestronaut #maintenance #security
